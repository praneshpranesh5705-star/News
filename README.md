# TamilNadu AI News

A mobile-first Tamil Nadu AI news website starter built with Next.js + TypeScript.

## Included
- Tamil Nadu district selector
- Tamil/English-ready interface
- Latest and trending news cards
- Search
- Dark mode
- Text-to-speech
- Bookmarks
- AI assistant UI
- Responsive mobile layout

## Live API integration
The UI uses demo content so it runs immediately. For production, connect a permitted news API/RSS feed in `app/api/news` and replace the demo data. Do not scrape or republish copyrighted article bodies without permission.

## Run
npm install
npm run dev

Then open http://localhost:3000
